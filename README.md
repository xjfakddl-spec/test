# It's me

## 주요기

- 반응형 웹 디자인
- PC / 태블릿 / 모바일 화면 대응
- Flexbox와 Grid를 이용한 레이아웃
- 키보드 Focus 스타일 적용
- Sticky Header

## 사용 기술

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Query

## 배운 점

- CSS 단위와 반응형 값의 차이를 이해했습니다.
- Media Query를 이용해 화면 크기에 따라 레이아웃을 변경했습니다.
- 웹 접근성을 고려해 heading, alt, focus를 점검했습니다.
